# Data

The leads dataset is **not public and not committed** to this repo. I received it as course
material, so I don't redistribute it. If you have a copy, place it at `data/raw/leads.csv`.

Without it, `make test` and `make demo` run the full pipeline on synthetic leads generated by
`leadscore.synthetic.make_leads()`, which has the same schema. Those numbers mean nothing about
real leads.

## Schema (4,612 rows, 15 columns in the original file)

| Column | Type | Values / meaning |
|---|---|---|
| `ID` | string | Unique lead identifier (dropped before modeling) |
| `age` | int | Age of the lead |
| `current_occupation` | category | Professional, Unemployed, Student |
| `first_interaction` | category | Website, Mobile App |
| `profile_completed` | category | Low (0–50%), Medium (50–75%), High (75–100%) |
| `website_visits` | int | Number of visits to the website |
| `time_spent_on_website` | int | Total time on the website (seconds) |
| `page_views_per_visit` | float | Average pages viewed per visit |
| `last_activity` | category | Email Activity, Phone Activity, Website Activity |
| `print_media_type1` | Yes/No | Saw a newspaper ad |
| `print_media_type2` | Yes/No | Saw a magazine ad |
| `digital_media` | Yes/No | Saw a digital ad |
| `educational_channels` | Yes/No | Heard about the company on education forums or sites |
| `referral` | Yes/No | Heard about the company through a referral |
| `status` | 0/1 | Target: 1 if the lead became a paying customer |

`leadscore.data.validate()` checks these columns and category values before any modeling.
